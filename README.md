# 错题闭环本 · 八年级下册

给初中生用的错题本：**拍照录入 → 自动安排复测 → 三次独立做对才过关**。

- 科目：语文（统编版）、数学（浙教版）、英语（人教版）、科学（浙教版），八下章节与知识点
- 复习节奏：录入当天订正 → 3 天后复测 → 2 周后再复测；中途做错重新计时
- 照片自动压缩存浏览器本地（IndexedDB），不上传任何服务器
- 支持导出/导入备份、离线使用（PWA，可加到手机主屏幕）

## 使用

直接用浏览器打开 `index.html`，或在目录下起本地服务：

```bash
python3 -m http.server 8123
# 访问 http://localhost:8123
```

手机和电脑同一 Wi-Fi 时，手机浏览器访问 `http://<电脑局域网IP>:8123`。

## 数据

所有错题和照片只保存在当前浏览器里。换设备或清理缓存前，先在"备份"页导出 JSON 文件。
